💡 Proper Database Architecture for Creative Portfolios

Best Practice

❌ What NOT to do

Storing 50MB MP4 videos or 5MB images directly inside database columns (as BLOBs). This bloats database RAM, causes query locks, prevents browser range-seeking, and creates serious playback hiccups.

✅ What this server does

Filesystem stores media files in uploads/ with HTTP 206 Byte-Range streaming (instant video seeking). SQLite stores lightweight metadata (URLs, titles, sizes, tags) and full poem text.

Frontend Integration Reference

When you're ready to build your portfolio frontend (React, Vue, Vanilla JS), use these standard endpoints:

GET /api/media?type=video

Fetches all video metadata for your video reel showcase.

GET /api/media?type=image

Fetches all hobby photos for your gallery grid.

GET /uploads/videos/{filename}

Streams the MP4 video using HTTP 206 Byte-Range requests for instant scrubbing/seeking.

GET /api/poems

Returns list of poems with mood, tags, and formatted stanzas.

POST /api/upload

Upload new video or image via FormData. Saves file to disk & creates record in SQLite.
